## 1. “提前宣布大捷”失败模式如何进入市场异常→FINDING 管道

关键洞察：**这类失败模式在市场上的信号，不是“说错了”，而是“说得太早”。**

所以进入管道的方式应该是：

**异常源**
- 官方/权威账号发布胜利、突破、签约、验收、量产类声明
- 同一主体在短时间内密集发布同方向利好
- 发布时点显著早于可验证第三方证据（合同备案、海关数据、卫星图、财报、验收文档、竞品反应）

**市场异常层**
- 该主体关联标的在发布前后出现异常收益、异常波动率、异常成交量
- 期权偏斜、信用利差、供应链同业联动出现同向异动
- 后续 N 日内出现“回吐/反转/澄清/删帖/改口”

**FINDING 层**
- 不应直接输出“消息为假”
- 应输出：**“发布-证据时序错位 + 市场先验反应 + 后续未兑现”三元组**
- 置信度分级：
  - L1：仅时序错位
  - L2：时序错位 + 市场异常
  - L3：时序错位 + 市场异常 + 后续未兑现/被澄清

这样它进入的是**异常检测与风险标记管道**，不是事实核查管道。

## 2. 反夸大校验怎么接

反夸大校验不应做成“语义真假分类器”，而应做成**证据成熟度校验器**。

建议四个校验闸：

1. **证据成熟度闸**
   - 声明类型 → 所需最低证据等级
   - 例如“量产”需产线图/出货单/客户确认；“大捷”需可核验战果/第三方影像/对方承认

2. **时序闸**
   - 声明时间 vs 证据出现时间
   - 若声明显著早于证据，直接降权

3. **市场一致性闸**
   - 若市场反应远大于可验证基本面变化，标记“预期透支”

4. **回撤闸**
   - T+N 内是否出现澄清、删帖、改口、数据下修
   - 有则升级为高置信 FINDING

这样反夸大校验的输出不是“真/假”，而是：
**“该声明当前证据不足，且市场已按高置信定价，存在回撤风险。”**

## 3. 降频管道要不要加人眼审图闸

**要，但不是全量加，而是分层加。**

建议：

- **自动层**：全部时序错位 + 市场异常进入降频候选
- **人眼闸只加在两类**：
  1. L2 以上且涉及高冲击标的/板块
  2. 自动层分歧大（市场异常强但证据弱，或证据强但市场无反应）

人眼审图闸的职责不是判断真假，而是：
- 确认时序错位是否真实
- 确认市场异常是否关联
- 确认是否存在合理替代解释
- 决定是否升级 FINDING 或降级丢弃

**不建议全量人审**，否则降频管道会变成人工内容审核线，吞吐崩掉。

## 4. 可行性

**可行。** 因为这类失败模式有稳定可观测特征：

- 发布主体集中
- 声明类型可分类
- 证据出现时间可追踪
- 市场反应可量化
- 后续兑现可回看

难点不在模型，而在：
- 证据时间戳的权威源接入
- 跨语言/跨平台发布追踪
- 市场异常与声明的因果归因
- 避免把“正常前瞻指引”误杀

所以可行性高，但需要**先定义声明分类体系与证据等级表**。
