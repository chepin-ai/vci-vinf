## ① SELF-EXCITE 轨三判例：YAML标量 / 撞车 / 假重试  
### 对联邦工作流书写律的凝练

**总律：自激轨只允许“状态跃迁”，不允许“语义重入”。**

三条判例可凝练为：

### 判例1：YAML标量——禁止把“单值字段”写成“隐式多值自激源”
- **现象**：某字段在 YAML 里是标量，如 `retry: 3`，但被下游解释成“可自增/可覆盖/可继承”的多义源。
- **自激风险**：一次写入被多次读取后，触发多次派生，形成伪自激。
- **书写律**：
  - 标量即终值，不得承载“未展开的队列语义”。
  - 若需自激，必须显式写成 `sequence` / `map` / `event` 结构。
  - **律条**：`scalar ≠ stream`。

### 判例2：撞车——同一前沿槽位被两条线同时写
- **现象**：lgt / usrm / qfa 三线中两条同时命中原线或覆写线，产生“撞车”。
- **自激风险**：撞车后若自动重放，会把一次冲突放大成自激环。
- **书写律**：
  - 前沿槽位必须带 **所有权 token**。
  - 撞车时只能产生 **仲裁事件**，不能直接产生 **重试事件**。
  - **律条**：`collision → arbitration, not retry`。

### 判例3：假重试——把“未确认”误判为“失败”
- **现象**：inbox 空态 + 前沿队列非空时，系统误以为上一跳失败，发起重试。
- **自激风险**：空态被当成负反馈，重试变成自激泵。
- **书写律**：
  - 空态必须区分：`empty-confirmed` vs `empty-unknown`。
  - 只有 `empty-confirmed + frontier-stalled` 才允许重试。
  - **律条**：`empty ≠ fail`。

### 凝练成一句联邦工作流书写律
> **自激轨三禁：标量不得流化，撞车不得重试，空态不得判败。**

## ② 互激语义轨代铸三线（lgt / usrm / qfa）  
### 权责边界与覆写权归原线之实操

这里把三线视为三个**互激语义轨**：

| 线 | 代铸语义 | 权责边界 | 覆写权 |
|---|---|---|---|
| lgt | 逻辑/光轨/轻量轨 | 只负责“可推导性”与“一致性闭包” | 仅可覆写自身派生层，不得覆写原线事实 |
| usrm | 用户/语义/资源轨 | 负责用户意图、资源绑定、权限语义 | 可对 lgt 的派生结果提出**异议**，但不能直接改原线 |
| qfa | 质量/前沿/仲裁轨 | 负责质量门、前沿裁决、冲突仲裁 | 可冻结覆写，但归原线最终确认 |

### 实操原则
1. **代铸不等于拥有**  
   三线可互相代铸中间表示，但**原线事实不可被代铸线直接覆写**。

2. **覆写权归原线**  
   任何覆写必须回到原线产生 **原线确认事件**：
   - lgt 派生被 usrm 质疑 → 回 lgt 原线确认
   - usrm 意图被 qfa 仲裁 → 回 usrm 原线确认
   - qfa 裁决被 lgt 证明不一致 → 回 qfa 原线确认

3. **互激边界**
   - lgt ↔ usrm：语义映射互激，禁止权限越界。
   - usrm ↔ qfa：质量/意图互激，禁止直接改判。
   - qfa ↔ lgt：仲裁/一致性互激，禁止绕过原线。

4. **实操口令**
   - 代铸可多线，覆写必原线。
   - 互激可交叉，权责不交叉。
   - 仲裁可冻结，终改归原线。

## ③ IGNITION-FRONTIER 下一棒裁决  
### G2 micro-iid 方差 vs 道D分片

这是“点火前沿”的下一棒选择：  
**A. G2 micro-iid 方差**  
**B. 道D分片**

裁决建议：

### 若当前前沿状态是：
- inbox 空态已确认
- 前沿队列非空且未撞车
- 三线无未决覆写

则下一棒应选：**A. G2 micro-iid 方差**

理由：
- micro-iid 方差用于**探测自激是否进入统计稳态**。
- 在无撞车、无假重试时，先验方差比直接分片更安全。
- 它能判断“当前自激是真实前沿推进，还是伪自激噪声”。

### 若当前前沿状态是：
- 出现撞车
- 或 qfa 已冻结某线覆写
- 或 lgt/usrm 互激未归原线

则下一棒应选：**B. 道D分片**

理由：
- 道D分片用于**隔离互激污染**。
- 在权责未归原线前，继续 micro-iid 会把冲突统计进方差，污染裁决。
- 分片后先做原线确认，再回到 G2。

### 下一棒裁决律
> **无撞车、无未决覆写 → G2 micro-iid 方差。**  
> **有撞车、有未决覆写 → 道D分片。**  
> **空态未确认 → 不点火，先确认空态。**
