## 一、议题一逐项判定

### ① §2.4 退出路径枚举 B1–B7 补正

**判定：PASS**

**指名理由**：v0.3 已增 B7 触发器（触发面已入库），v0.5 仅补正**枚举列举遗漏**（B1–B6 → B1–B7），属**列举性对齐**，不引入新实体、不改动 B7 触发语义。因此不构成 §2.4 实质条款变更，无需重开 EXT11 全票面。补正后 §2.4 枚举与触发器集合闭合一致。

### ② §3.2-6 跨案污染 ⇒ REJECTED 封闭集增录 · 程序确认

**判定：确认成立（CONFIRMED）**

**指名理由**：
- **封闭集增录**在程序法上要求判定席**确认/撤回**二择一，不得默认生效——本裁定取“确认”。
- 增录内容与 ⑤ 设立的**时点分界规则**（受理时可识别⇒REJECTED）在语义上互洽：REJECTED 作为终态处置级，必须进入 §3.2-6 封闭集，否则 ⑤ 的“受理时可识别”分支无落点。
- 与 ④b 统一登记面兼容：污染事件以统一 schema 归集，REJECTED 增录不另开登记面。
- 确认后 §3.2-6 封闭集基数 +1，下一判次需随案复核该计数（见第六节残余项）。

**撤回不成立之理由**：若撤回，则 ⑤ 的 REJECTED 分支失去封闭集锚点，会退化为“游离处置级”，违反封闭集原则。

### ③ §9 Q6 热轨 DONE 证据模式二选一：Q6-a 维持 / Q6-b 扩展

**判定：PASS（采纳 Q6-b 扩展）**

**指名理由**：
- Q6-a（fallthrough 证据模式**永不**发放热轨 DONE）为**过窄封闭**：fallthrough 不可达即 DONE 永不可发，等于在 §9 层面单方面废除热轨 DONE 机态，与 §2.3 合取语义相冲。
- Q6-b（增捕获 **wall + log_digest + §2.4 逐项排除指针**三件套，缺一不发放）满足：
  - **可验证性**：wall/log_digest 可哈希复算；
  - **可追溯性**：§2.4 逐项排除指针把“为何可 DONE”锚定到枚举 B1–B7 的排除路径；
  - **语义无损**：Q6-b 明确“§2.3 合取语义不变”，不引入新的合取/析取变更。
- 三件套**缺一不发放**与 ④a UTC 单一时间域一致（wall 必须是 Z）。

**驳回 Q6-a 之理由**：以“永不发放”替代“证据不足不发放”，属机态废除，越出 §9 授权面。

**判定：PASS**

**指名理由**：

### ④b §3.1 越权引用与 §3.2-6 污染事件同一违规登记面

**判定：PASS**

**指名理由**：
- 两事件共享**同一违规语义面**（均为“不合规引用/污染引入”），统一 schema 归集不丢失区分度，因 schema 含 `条款锚`（区分 §3.1 / §3.2-6）与 `处置级`（区分 REJECTED / BLOCKED）。
- 字段完备性核验：`事件id / 时刻 / 案id / 格id / 条款锚 / 处置级 / 证据指针` 七字段足以支撑 ⑤ 的时点判定与 ① 的枚举复核。
- 与 ④a 兼容：`时刻` 字段强制 Z。

### ④c recoverable=false 之格仍属 BLOCKED 机态

**判定：PASS**

**指名理由**：
- **不迁移、不终态**：recoverable=false 不是新机态，不触发机态迁移，也不进入终态集。
- **唯一出口=判定席裁决**：与 ② 的“确认/撤回”程序、⑤ 的处置级判定同源，避免自动终态化。
- 与 REJECTED 的区别被守住：REJECTED 是**终态处置级**（②⑥），BLOCKED 是**中间机态**（④c、⑤受理后识别分支）。
- ⑥“REJECTED 无计时”不适用于此，因该格非 REJECTED。

---

### ⑤ 跨案污染时点分界

**判定：PASS**

**指名理由**：
- 受理时**可识别** ⇒ **REJECTED**（终态处置级，入 §3.2-6 封闭集，见 ②）；
- 受理后**识别** ⇒ **BLOCKED（B2 同级）+ 违规登记**（④b 同一 schema）。
- 分界判据**唯一**（受理时点），与 ④a UTC 单时钟域一致，无重叠、无空隙。
- “B2 同级”为本条自设等级锚，与既有 B 触发集兼容，不新增枚举（故不触碰 ① 的 B1–B7 闭合）。

---

### ⑥ REJECTED 不参与 §8 定序、不构联合态、无计时

**判定：PASS（确认性补注）**

**指名理由**：
- 性质为**确认性补注**，不引入新规则，仅显式化 REJECTED 的既有效应边界。
- 三条负向效应（不定序 / 不联合 / 不计时）彼此一致：终态处置级若参与定序或联合态，会反噬 ② 的封闭集稳定性和 ⑤ 的分界确定性。
- 与 ④c 形成对称：BLOCKED 有出口（裁决），REJECTED 无计时——机态与终态的边界因此清晰。
