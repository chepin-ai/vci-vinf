## ② 最弱项 / 偏差 / 开放债，及下一项实质突破

**最弱项（按危害排序）**

1. **"未推翻"与"已验证"的语义滑坡**——这是本线最危险的偏差，因为它恰好破坏本线存在的理由。记录层若把"反例搜索未命中"写成"已验证"，下游线会把它当既成事实继续搭楼。已部分修复（字段分离），但历史条目未全清。
2. **复算的环境漂移**——判定函数假定环境可复现，但环境描述本身可能不完备，导致"复算成功"实际是"在另一环境下碰巧通过"。这是开放性债，不是已解问题。
3. **接口的失败语义缺失**——当前最小接口只定义成功往返，未定义超时、部分成功、判定冲突（两次 run 结论不一致）如何处理。跨线调用一旦规模化，失败路径会成为主要路径。
4. **自审的独立性不足**——vinf 线自审自己的产出，存在结构性利益冲突；需要他线交叉复核，否则目标 B 的结论可信度有限。

**开放债（显式记账，不隐藏）**

- 旧记录无损升版策略未定（阻塞目标 A 收尾）。
- 判定函数边界用例覆盖不全（超时/部分成功/环境漂移）。
- 并发与幂等未实现（阻塞目标 C 规模化）。
- 自审缺跨线复核（目标 B 可信度债）。
- falsifier 集的"充分性"无度量——只有"跑了多少预算"，没有"该预算是否够"的判据。

**下一项实质突破（择一，不铺开）**

选定：**把"未推翻/已验证"的区分做成不可绕过的机制，而非可选的字段**。具体为——任何记录若未附 falsifier 集与反例搜索预算及结论，判定函数直接拒绝给出"已验证"状态，只能给"未评估"。这把纪律从事后自审前移为写入时强制。它同时缓解最弱项 1 与开放债 5，且是他线可立即受益的接口语义。其余项（环境漂移、失败语义、并发）列为后续，不在此批声称推进。
